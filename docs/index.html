Liquid Glass for React Native

Tab bars, headers, toggles, sliders, menus and search that plug straight into React Navigation. Native glass on iOS 26, Compose glass on Android, and every animation runs natively.

iOS 26 UIGlassEffect Android · Kyant0 backdrop New Architecture

A CSS sketch of LiquidBottomTabBar. Click a tab. The real component draws native glass with a liquid drop that follows your finger.

Overview

@mohamedabdelnaby/react-native-liquid gives React Native apps the iOS 26 Liquid Glass look on both platforms, with components shaped to drop into React Navigation as custom tab bars and headers.

LiquidBottomTabBarFloating bar with a liquid drop, search and keyboard lift.
LiquidTopTabBarFloating segmented bar that follows the pager while swiping.
LiquidHeaderFloating controls or a full glass bar for any stack.
LiquidGlassViewThe glass material as a view, with morphing.
LiquidToggle · LiquidSliderNative switch and slider with glass thumbs.
LiquidMenu · SearchGlass menus and a search button that morphs into a field.

Installation

yarn add @mohamedabdelnaby/react-native-liquid react-native-safe-area-context

Install the navigators you use, for example @react-navigation/bottom-tabs, @react-navigation/material-top-tabs or @react-navigation/native-stack. They are optional peer dependencies.

Then rebuild the native app:

cd ios && pod install && cd ..
npx react-native run-ios
npx react-native run-android

Requirements

  • React Native 0.80+ with the New Architecture (Fabric). Works in React Native CLI apps and Expo dev builds, not in Expo Go.
  • iOS: build with Xcode 26+ to get Liquid Glass on iOS 26 devices. Older iOS versions get a system blur material.
  • Android: Kotlin 2.2+ in the app. Glass needs Android 12+, lens refraction Android 13+. Older versions get a frosted material.

How it works

iOS

  • Glass is UIGlassEffect and UIGlassContainerEffect in Fabric components.
  • The tab bar drop is a clear glass lens driven by a CADisplayLink spring.
  • UISwitch, UISlider and UIButton menus give the system glass controls.

Android

  • Each glass view hosts a small Compose view drawn with AndroidLiquidGlass (vibrancy, blur, lens).
  • The views behind the glass are recorded into a RenderNode every frame, so scrolling content stays live under the bars.
  • Springs run on Choreographer, never on the JS thread.
Content in a separate surface (SurfaceView, some video and map views) is not sampled on Android, and glass shapes do not merge there: LiquidGlassContainer is a plain view on Android.

Bottom tab bar

A floating glass bar for @react-navigation/bottom-tabs. Pressing lifts a glass drop out of the pill. The drop follows your finger, stretches with its speed, magnifies the tabs and melts back into the pill. In light mode the bar is frosted white with a soft gray pill; in dark mode it is frosted dark gray with a darker pill.

import { createBottomTabNavigator } from '@react-navigation/bottom-tabs';
import { createLiquidBottomTabBar } from '@mohamedabdelnaby/react-native-liquid';

const Tab = createBottomTabNavigator();
// Create the tabBar function once, outside of render.
const tabBar = createLiquidBottomTabBar({ search: { placeholder: 'Search' } });

export function Tabs() {
  return (
    <Tab.Navigator tabBar={tabBar}>
      <Tab.Screen name="Home" component={Home}
        options={{ tabBarIcon: ({ color }) => <HomeIcon color={color} /> }} />
      <Tab.Screen name="Settings" component={Settings} />
    </Tab.Navigator>
  );
}

The bar floats over the screens. Pad scrollable content with useBottomTabBarHeight(); the bar reports its height to it.

It reads tabBarIcon, tabBarLabel, tabBarShowLabel, tabBarBadge, tabBarBadgeStyle, tabBarActiveTintColor, tabBarInactiveTintColor, tabBarLabelStyle, tabBarAccessibilityLabel, tabBarButtonTestID, tabBarHideOnKeyboard and tabBarStyle: { display: 'none' }, and emits tabPress and tabLongPress.

Header

A glass header for native-stack, stack, bottom-tabs and drawer navigators.

import { createNativeStackNavigator } from '@react-navigation/native-stack';
import { createLiquidHeader } from '@mohamedabdelnaby/react-native-liquid';

const Stack = createNativeStackNavigator();
const header = createLiquidHeader(); // or createLiquidHeader({ variant: 'bar' })

<Stack.Navigator screenOptions={{ header, headerTransparent: true }}>
  …
</Stack.Navigator>
  • variant: 'floating' (default): a round glass back button, the title, and headerRight in a glass capsule, over the content like iOS 26.
  • variant: 'bar': a full-width glass bar.

With headerTransparent: true the content scrolls under the glass; pad it with useLiquidHeaderHeight() (safe area + LIQUID_HEADER_HEIGHT, 56). Options read: title, headerTitle, headerTitleAlign, headerTitleStyle, headerTintColor, headerLeft, headerRight, headerBackTitle. Config: variant, glassStyle, glassTintColor, colorScheme, style.

Glass view & container

import { LiquidGlassView, LiquidGlassContainer } from '@mohamedabdelnaby/react-native-liquid';

<LiquidGlassView cornerRadius={24} style={{ padding: 16 }}>
  <Text>On glass</Text>
</LiquidGlassView>

// Neighbouring glass merges and morphs (iOS 26).
<LiquidGlassContainer spacing={8} style={{ flexDirection: 'row', gap: 16 }}>
  <LiquidGlassView morph interactive cornerRadius={22} style={{ width: wide ? 104 : 44, height: 44 }} />
  <LiquidGlassView morph interactive cornerRadius={22} style={{ width: 44, height: 44 }} />
</LiquidGlassContainer>
Keep a container's spacing below the gap between its children. The shapes then fuse only while they morph and rest apart. A larger spacing makes them bulge toward each other.

Buttons

<LiquidButton title="Continue" variant="prominent" onPress={next} />
<LiquidIconButton accessibilityLabel="Add" onPress={add}><PlusIcon /></LiquidIconButton>

LiquidButton: title, icon, variant ('glass' or 'prominent'), tintColor, size ('small' | 'regular' | 'large'), textStyle, plus the glass and press props. LiquidIconButton: children and size (diameter, 44).

Toggle

<LiquidToggle value={enabled} onValueChange={setEnabled} />

Pressing turns the thumb into a clear glass lens that grows past the track, slides while the track fills with color, then settles back into a solid thumb. Native on both platforms (UIKit and Compose), and every part can be recolored. Props: value, onValueChange, disabled, onTintColor (track when on), offTintColor (track when off), thumbTintColor (thumb at rest), lensTintColor (glass lens while pressed), colorScheme, style, accessibilityLabel, testID. Horizontal drags are not stolen by a parent scroll view.

Slider

<LiquidSlider value={volume} onValueChange={setVolume} step={0.1} />

Props: value, minimumValue (0), maximumValue (1), step (0 = continuous), onValueChange, onSlidingStart, onSlidingComplete, disabled, tintColor, colorScheme, style.

Segmented control

<LiquidSegmentedControl segments={['Day', 'Week', 'Month']} selectedIndex={i} onChange={setI} />

Props: segments, selectedIndex, onChange, height (36), glassStyle, colorScheme, activeTintColor, inactiveTintColor, selectionColor, disabled, style, textStyle.

Search

LiquidSearchBar

<LiquidSearchBar value={query} onChangeText={setQuery} placeholder="Search" />

A glass search field. Takes the TextInput props plus glassStyle, colorScheme, height (44), inputStyle and onClear.

LiquidExpandableSearch

<LiquidExpandableSearch value={query} onChangeText={setQuery} placeholder="Search settings">
  <Text>Controls</Text>   {/* shown next to the button while collapsed */}
</LiquidExpandableSearch>

A round glass button that morphs into a field with a separate close button, 16 pt apart. Props: expanded / defaultExpanded / onExpandedChange, value, onChangeText, onSubmit, placeholder, height (44), glassStyle, glassTintColor, colorScheme, style. The bottom tab bar's search option uses it.

Theme & utilities

const { scheme, colors } = useLiquidColors('system');
if (isLiquidGlassSupported) { … }
  • useLiquidColors(setting?) returns the scheme and the palette used by the components: label, secondaryLabel, tint, success, selection, tabSelection, tabBarGlass, topTabLens, track, thumb.
  • getLiquidColors(scheme) and useLiquidColorScheme(setting) for use outside components.
  • isLiquidGlassSupported: true on iOS 26+ and Android 12+.
  • createLiquidBottomTabBar, createLiquidTopTabBar, createLiquidHeader return render functions; create them once outside of render.

Troubleshooting

"No member named … in …Props" when building iOS

The native props changed. Run pod install again to regenerate codegen, then rebuild.

"Unable to load script" on an Android phone

The phone lost its connection to Metro, often after a USB reconnect. Forward the Metro port again:

adb reverse tcp:8081 tcp:8081

Content does not show through the glass on Android

Views drawn in their own surface (SurfaceView, some video and map views) cannot be sampled. Place glass over regular views.

Glass is blank after navigating back on Android

Update to the latest version: glass views keep their composition while react-native-screens detaches them.
